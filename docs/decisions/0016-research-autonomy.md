# 0016 — Research autonomy within initial authority

Status: **accepted operator direction, 16 November 2026; implemented; bounded native workflows verified**.
The initial implementation instruction deferred full E2E and provider runs. A later
16 November instruction explicitly authorized Terra to run full E2E, repair
prerequisites and rebuild runtime images, with Astra handling implementation fixes,
followed by PR publication. See the [dated delivery evidence](../wiki/oslit-research-autonomy-delivery-2026-11-16.md).
Fresh-target research and the native-agent comparison remain operator-owned. This
record grants no engagement or external-action authority.

## Decision and reason

The operator approved the [consolidated plan](../research/oslit-research-autonomy-plan-2026-11-16.md)
and [requirement deletion map](../research/oslit-requirements-deletion-map-2026-11-16.md),
authorized implementation using the existing v2 work, and assigned minimal local
verification to Luna. Native capable researchers should choose productive work
inside initial signed authority. Universal research sequences and repeated semantic
forms had become unnecessary constraints. Preserve concrete permission, evidence
integrity, ownership, independent review and recovery boundaries.

New scopes select `authority_policy: research-autonomy-v1`. Frozen initialization
selects the behavior and guidance. Existing `initial-scope-v1`, earlier v2, v1 and
queue records keep their original meaning and gates; no automatic migration or
historical regrading occurs.

- Strategy challenges are advice. They neither exclude resources, force a fixed
  lead-replacement countdown nor prevent otherwise supported closure. Concrete
  ownership, authority and uncertain-effect stops remain.
- Exact execution facts bind bytes, observations, accounts, environment and actors.
  Independent reviewers assess causal controls, clean reproduction and scientific
  adequacy. A valid independent reproducer need not use identical probe bytes or
  be the final reviewer personally. Actual separate worker/session identity remains
  required. Patch acceptance uses relevant original/patched observations, not an
  obligatory four-purpose matrix.
- Signed effects are admitted against actual resources, accounts, destinations and
  limits, without a universal self/stored/cross-user ladder. Operator-selected
  sequences and real state dependencies still apply.
- Total invocation/duration limits are optional. A supplied `worker_seconds` cap
  measures elapsed parent execution time. Ten minutes with two concurrent helpers
  is ten minutes, not thirty; actual provider requests/tokens include all children.
  Machine capacity, short leases, revocation and unknown-effect recovery remain.
- Native Codex/OMP helpers inherit authenticated parent authority and resources.
  They are not controller workers or independent reviewers. No new model-routing
  choice is introduced.
- Ordinary shared notes and source links preserve evolving assumptions, bounded
  negatives and surviving partial effects across context/process loss. No graph,
  permanent planner or compulsory chain format is added.
- A versioned file library supplies active offline/public references and experimental
  techniques. Public-reference access is an optional separate initial grant. Selected
  bytes and origin are retained automatically, including files above the 4 MiB
  evidence-object limit. Storage failure delivers otherwise permitted content with
  explicit `not_retained` status; exports identify the gap.
- Exact-version recommendation requires independent changed-case transfer and a
  meaningful counterexample with actual resolvable evidence. Save experimental
  ideas immediately; evaluation is optional and never blocks ordinary research or
  closure. New package bytes or broader claims need new evidence. Contrary evidence
  can narrow or withdraw recommendations without deleting earlier records.

The smaller alternatives are deliberate: reuse native sessions/tools and the
existing journal, file store, acquisition transport, board and protected executor.
A custom graph store, fixed swarm, permanent evaluator service and background
crawler are out of scope. Model upgrades can replace optional aids when comparable
outcome evidence justifies it; immutable permission/evidence contracts remain.

## Implementation and evidence boundary

[The operator guide](../agents/engagement.md) and [library guide](../agents/knowledge-library.md)
describe the public workflow. New input templates select this policy and omit total
caps by default. Policy-specific method/protocol files leave historical guidance
unchanged. Failure scenarios precede implementation; focused local verification
covers changed mechanisms. A local check is not native provider qualification,
sustained operation, comparative research benefit or fresh-target acceptance.
