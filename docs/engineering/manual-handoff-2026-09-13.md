## Implementation plan

1. Make bootstrap order explicit: prepare source, conditional corpus, complete scope/goal draft and runner-readiness facts → real signature → authorized init
   → admitted read-only handoff → verify execution readiness → recon. Existing engagements
   use read-only admission; never initialize over them or fabricate signatures.
2. Put the common entry/resume procedure in the existing fallback reference and link it from all
   active callers. Remove repeated generated-view transcription and automatic re-acquisition.
3. Preserve root gates, independent cold review and source-faithfulness requirements. No runner,
   backend, CLI, configuration, dependency, new abstraction or benchmark framework is added.
