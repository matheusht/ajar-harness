# Legacy queue/record engagement template

Copy this template into the target's own repository only for an existing
queue/record workflow or work explicitly assigned to that runtime. New local
source research follows `<harness-checkout>/docs/agents/native-local-research.md`:
write a target-local signed scope and a separate brief/allowance, then use the
native run root. It does not initialize this template's ledger or queue.

and the task's actual run authorization remain separate.
