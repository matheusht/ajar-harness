## Surface (family, webpack stack; 1 root cause)

- **Root cause:** `ensureValidSubPath` (`packages/angular/build/src/utils/i18n-options.ts:69`, regex `/^[\w-]*$/`) is applied ONLY to explicit `subPath` options (`i18n.sourceLocale.subPath` L128, `i18n.locales[<key>].subPath` L176) — **never to the locale KEY itself** (`Object.entries(metadata.locales)` L163) nor to string-form `i18n.sourceLocale` (L103-104, `ensureString` only). The locale key becomes the default output subPath verbatim (`subPath: subPath ?? locale`, L194).
- **Members (verified):**
  - **A2** `packages/angular_devkit/build_angular/src/utils/output-paths.ts:17` (webpack twin) — `join(baseOutputPath, i18n.locales[l].subPath)` + `mkdirSync recursive` — malicious key escapes the output base.
  - **A3** `packages/angular_devkit/build_angular/src/utils/i18n-webpack.ts` (webpack process-bundle path) — key-derived subPath flows into output writing.
  - **B** string-form `i18n.sourceLocale` — same bypass class (unvalidated string becomes subPath).
  - **C** `i18n-webpack.ts:52-58` `configureI18nBuild` → `projectRequire = createRequire(projectRoot + '/')` → `findLocaleDataPath` (L145-153) — the malicious key resolves a module via up-tree/absolute resolution; the module's content is read and **Babel-transformed into the webpack bundle** (executed in the client bundle AND in the legacy-SSR server process — E2-R4/C4F venue correction).
- **WAVE-B MEMBERS E + F (E2-B2/ECCS, verified at source):**

The family is therefore **webpack/legacy-stack only**; the application builder is a negative control for the write side.

## Mechanism (verified at pin)

1. Workspace `angular.json` → `i18n.locales = { "../../evil": { "translation": "..." } }` (or string-form `sourceLocale`) — the KEY is unvalidated at `createI18nOptions` (schema BCP-47 `pattern` exists on the `locales` property but is **never enforced on the `ng build` path** — verified: workspace-schema constraints exist but the build path skips schema validation of the i18n block).
2. Write side: the key becomes the output subPath → `join(outputBase, key)` → `mkdir + writeFile` outside the output base (webpack builders; live-verified with the real `ensureOutputPaths` bundle — malicious key accepted, explicit `subPath` control throws).
3. Read side (C): `createRequire(projectRoot + '/')` anchored at the project root → a deep-dot key (e.g. `../../..`) resolves up-tree/absolute → `findLocaleDataPath` returns the resolved file → content read + Babel transform → prepended into the webpack bundle (executes in the **client bundle AND in the legacy-SSR server process** — boot-time module evaluation, not per-request; N1D E2E confirmed boot-time; the venue correction in the Impact section governs). Reach bound: `findLocaleDataPath` returns null when resolution fails; in a NORMAL project `@angular/common` IS installed so a plain malicious key resolves inside the real package subpath and fails to load — the member requires BOTH a deep-dot key AND an attacker-controlled package present in the resolution chain (RV-C1-B narrowing). The Babel transform constrains the read to parseable JS/JSON (binary targets abort the build — a bound, not a bypass).

## Remediation

1. Single choke-point: validate locale keys and string-form `sourceLocale` with the same regex as `ensureValidSubPath` at `createI18nOptions` (keys at L163, sourceLocale at L103-104) — one change covers members A2/A3/B/C.
2. Extend the same validation to the localize schema (`pattern` on `locales` propertyNames) AND enforce schema validation on the build path's i18n block (the existing BCP-47 pattern is unenforced).
3. Regression test: malicious locale key → build fails at option normalization (not at write time); explicit-subPath control stays.
4. Contain + extension-allowlist the TRANSLATION path (member E) at createI18nOptions (validate against a URL-safe pattern; the read is uncontained).
5. Escape/validate `baseHref` at the schema or the `emitRaw` site (member F; the N2C discriminator: `emitRaw` head case vs `updateAttribute` base-tag case; note the CSP-conditional execution).
