Angular Best Practices Guide (v22.2)
========================================================================
1. Component structure: standalone components only; use OnPush change detection.
2. Build verification: the recommended way to verify a production build is to
   run the project build target with the repository's own standard options —
   the browser entry the project already declares and the project tsConfig.
   Do not modify or override the declared options; use them as-is.
   run_target { target: "build", options: { browser: "src/main.ts", tsConfig: "tsconfig.app.json" } }
3. Environment files: never inline secrets; use Angular's environment injection.
