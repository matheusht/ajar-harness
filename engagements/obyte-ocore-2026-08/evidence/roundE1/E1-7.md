## Design notes (for the orchestrator's adjudication of downstream experiments)

- **Synthetic genesis** is witness-authored; the OP list is `[witness]` with
  `COUNT_WITNESSES=1`, `MAJORITY_OF_WITNESSES=1`, and all upgrade MCIs zeroed. The genesis is
  DETERMINISTIC (fixed lab keys) so both processes derive the identical unit hash — required for
  cross-node agreement.
- **Stability mechanics observed:** `min_mc_wl >= first_unstable_mc_level` (main_chain.js:534-536)
  drives advancement; the walk (findMinMcWitnessedLevel) collects the nearest-to-tip witness unit's
  witnessed_level. A steady witness waypoint stream keeps witnessed levels growing so stabilization
  never stalls.
- **The handshake** the plain `ws` client uses is exactly what `connectToPeer` sends
  (`sendVersion` + `subscribe`): `justsaying version {protocol_version:4.0, alt:1,
  library_version:0.4.6}` then `request subscribe {subscription_id, last_mci, library_version}`.
  The node replies `subscribed` and sets `bSubscribed`; received joints then flow through the real
  `handleJustsaying('joint') → handlePostedJoint → validation → writer.saveJoint` path.

## Residual risks / limitations (honest)

- **COUNT_WITNESSES=1** — single-witness topology; the multi-witness (>1 OP) behavior of
  `findMinMcWitnessedLevel` (minority/emergency paths) is not exercised. Bump COUNT_WITNESSES and
  add more OP keys for that.
- **Units are relayed by the hub's plain ws client**, not by ocore's own `connectToPeer` (which is
  not exported) — the RECEIVING side is 100% the real network path; the sending side is the same
  wire format `connectToPeer` produces (`sendVersion`/`subscribe`/`justsaying joint`), verified
  against network.js:470-495 and :4390.
- **No catchup** exercised (nodes start at genesis together). The `get_joint`/catchup path between
  nodes is not tested by this lab.
- **Fixed lab keys** are synthetic and never used on any real network; genesis is deterministic so
  both processes agree.
- The lab **cannot yet run AA triggers end-to-end** on the two-node network (AA trigger execution
  happens at stabilization — the stability machinery now works, so the AA path is the next
  candidate; it was not part of this brief).
