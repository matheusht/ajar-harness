# Joined native autonomy: failure cases

Defined before adding the real-runtime fixture. Use only disposable owned source,
private signing key and deterministic provider. Run independently for Codex and
OMP. A result is a mechanics observation, not research success.

| Case | Required observation |
| --- | --- |
| Signed autonomy scope, native lead and helper | Parent uses the actual native tool protocol to spawn child; a child call uses the same protected authority and retained source resource. |
| Child completion and repeated usage | Exactly one helper identity, actual child session, output and nonduplicated cumulative usage are retained under the parent. |
| Stop while child active or parent revoked | Descendant stops, no further child tool action is admitted, and recovery verifies owned resources. |
| Read reference and materialize | A retained exact version is read by a native tool call and materialized in the isolated workspace with matching bytes. |
| Version changes or interrupted transfer | A selected version keeps its original bytes; replay does not silently substitute newer content. |
| Fetch succeeds but retention fails | Delivery is marked not retained and durable journal/export reports the limitation. |
| Technique published and challenged | Separate reviewer identity and changed-case/counterexample evidence are required for recommendation; later withdrawal is visible while old version and evaluation remain retained. |
| Lost owner and recovery | A new controller reopens the exact journal and reconciles worker and helper ownership without repeating an uncertain effect. |
| Reviewed closure and export | A fresh reviewer, independently retained evidence and clean result are checked; same engagement export has exact selected bytes, complete journal references and cleanup readback. |

A partial sequence must report its exact passed checks and missing rows. A scripted
provider cannot establish model-directed behavior. A live-provider smoke is a
separate result, not a replacement for a missing failure case or independent review.

## Local acquisition transport

Before implementing the local transport scenario: a signed-style acquisition route
must allow an owned TLS GET and retain the exact response digest; a credential
header, ungranted destination, and mutation request must not reach the receiver;
an interrupted response must not be recorded as complete. This checks local network
transport and binding only, not a native agent or Docker lab.
