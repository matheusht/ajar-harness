# Domain Pack: Consensus, Bridges, and Virtual Machines

Load this pack only when `skill_mode=domain` on blockchain client, consensus engine, cross-chain bridge, smart-contract VM, or DAG ledger code.

**Step-2 Divergence Exit Rule:** Trace the exact message route (`CheckTx` / `DeliverTx` / `FinalizeBlock` / P2P gossip / VM host import) first. When a verified upstream invariant check or deterministic serializer makes the defect unreachable, close the task immediately with `ajar task dry <task_id> --worker <id> --locus <file:line> --control "<reason>"`.

## Contrastive Pattern Matrix

| Pattern | Defect Pattern & Sinks | Compensating Control That Makes It Safe | 4-Arm Verification Recipe |
| --- | --- | --- | --- |
| **1. IBC / Cross-Chain Callback Reentrancy** | Packet lifecycle handler (`OnRecvPacket`, `OnAcknowledgementPacket`, `OnTimeoutPacket`) invokes an application/contract callback before writing packet commitment deletion, sequence increment, or escrow balance update (`ibc-callback-reentrancy`). | State commitment/acknowledgement deletion is written to KVStore **before** invoking untrusted module callbacks, or per-channel/escrow reentrancy guard rejects nested packet mutations. | Arm 1: Malicious callback re-enters transfer/timeout handler and double-refunds or mints unbacked vouchers. Arm 2: Honest IBC packet relay settles once. Arm 3: Commit packet deletion/escrow update prior to callback. Arm 4: Honest IBC packet relay passes. |
| **2. Non-Deterministic State Execution (Consensus Split)** | `DeliverTx` / `FinalizeBlock` iterates Go maps without sorting keys, reads wall-clock time (`time.Now()` instead of `ctx.BlockTime()`), uses architecture-dependent float math, or hashes non-canonical JSON/Protobuf encodings (`ibc-nondeterministic-execution`). | Deterministic sorted key iteration, canonical protobuf/amino deterministic marshaling, integer/fixed-point arithmetic, and block-header-derived timestamps across all state-committing paths. | Arm 1: Two simulated validator invocations on identical block inputs compute distinct `AppHash` / state roots. Arm 2: Standard transaction batch produces identical `AppHash`. Arm 3: Canonicalize ordering/encoding at `locus`. Arm 4: Both validator runs agree on `AppHash`. |
| **3. ICS-23 / Merkle Proof Verification Laxity** | Membership/non-membership verifier accepts caller-supplied `ProofSpec` parameters (`leafOp`, `innerOp` prefix lengths, hash algorithm, depth bounds), skips binding root to trusted consensus state, or accepts empty/interior nodes as leaves (`ics23-proof-verification-laxity`, Dragonberry class). | Verifier enforces hardcoded chain `ProofSpec` (`IavlSpec` / `TendermintSpec`), checks `minPrefixLength`/`maxPrefixLength` forbidding leaf-prefix collision with inner nodes, and binds root to finalized light-client header. | Arm 1: Forged proof for unescrowed key passes `VerifyMembership`. Arm 2: Genuine IAVL/SMT proof passes `VerifyMembership`. Arm 3: Enforce pinned `ProofSpec` and prefix bounds. Arm 4: Genuine proof continues to pass while forged proof fails. |
| **4. Unchecked Arithmetic / Nil-Pointer Chain-Halting Panic** | Network-reachable message, P2P frame, ABCI tx, or governance parameter reaches integer overflow/underflow, divide-by-zero, out-of-bounds slice index, or nil dereference inside `DeliverTx`/`EndBlock` without `recover()` or validation (`unchecked-arithmetic-panic-dos`). | `ValidateBasic` + keeper-level checked `sdk.Int` / `math.Int` bounds reject malformed inputs with a deterministic error before panicking consensus, or `CacheMultiStore` panic recovery charges gas and reverts tx cleanly without crashing `EndBlock`. | Arm 1: Unprivileged network message triggers unhandled panic in `FinalizeBlock`/`EndBlock` (halting block production). Arm 2: Valid message executes cleanly. Arm 3: Add explicit zero/bounds check returning `errorsmod.Wrap`. Arm 4: Valid message executes cleanly. |
| **5. VM Hook Lifecycle & Timeout Escape** | Smart-contract WASM/EVM host hook spawns goroutines/threads, skips gas metering before host allocation, or continues mutating state / holding locks after execution timeout cancellation (`vm-hook-lifecycle`). | Synchronous single-threaded VM metering charges gas **prior** to host memory allocation (`memory_allocation_bytes * cost`), and timeout atomically rolls back buffered state journal. | Arm 1: Crafted contract triggers unbounded host allocation or post-timeout state write. Arm 2: Metered contract executes within gas limit. Arm 3: Charge gas before allocation and join/abort hook on timeout. Arm 4: Metered contract passes. |
| **6. VM Opcode / Energy Accounting Undercharge** | Custom VM opcode schedule, precompile cost formula, or nested call energy refund charges `O(1)` gas for `O(N)` CPU/memory/I/O work or refunds more energy than consumed (`tvm-energy-accounting`). | Linear + superlinear memory/word cost formulas charge worst-case host work up front, and refunds are capped strictly below consumed execution gas. | Arm 1: Transaction within block gas limit consumes disproportionate wall-clock CPU/RAM (`> 10x` baseline) or nets positive energy delta. Arm 2: Standard opcode execution charges expected gas. Arm 3: Charge per-word/per-entry cost before host loop. Arm 4: Standard contract execution passes. |
| **7. Staking / Resource Float-to-Integer Precision Loss** | Freeze/delegate/unfreeze/slash share conversions use IEEE-754 `float64` or truncated integer division without remainder tracking, letting repeated split/merge cycles mint excess voting power or unfreeze more stake than locked (`resource-precision-loss`). | Exact 128/256-bit integer `mulDiv` rounding against the caller on both delegation and unbonding, with dust remainder retained in pool reserve. | Arm 1: Split-delegate-unfreeze sequence withdraws `> initial_stake` or leaves negative pool remainder. Arm 2: Single stake/unstake returns `<= initial_stake`. Arm 3: Replace float/truncated math with floor integer `mulDiv`. Arm 4: Single stake/unstake passes. |
| **8. DAG Canonicalization, JS Number Ledger Math & Upgrade Time-Travel** | DAG nodes hash/compare units differently (`dag-canonicalization-split`), compute token balances in JS `Number` above `2^53 - 1` (`dag-js-numeric-value-arithmetic`), gate consensus upgrades on parent unit index rather than MCI/timestamp (`dag-old-dag-rule-gating`), or verify private spend proofs asymmetrically between full and light nodes (`dag-spend-proof-uniqueness`). | Byte-exact canonical unit serialization, `BigInt` / fixed-width 64/128-bit integer ledger math with `MAX_CAP` guard, finalized-MCI upgrade enforcement blocking old-parent attachment bypass, and symmetric nullifier uniqueness checks. | Arm 1: Crafted unit causes full/light divergence, `Number.MAX_SAFE_INTEGER + 1 == Number.MAX_SAFE_INTEGER` value creation, or pre-upgrade parent bypass. Arm 2: Valid canonical unit commits identically across nodes. Arm 3: Enforce `BigInt`/canonical check/finalized upgrade gate. Arm 4: Valid unit commits cleanly. |
