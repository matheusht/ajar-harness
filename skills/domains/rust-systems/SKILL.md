# Domain Pack: Rust Systems, Parsers, and Runtime Boundaries

Load this pack only when `skill_mode=domain` on Rust systems, network parsers, storage engines, cryptographic wrappers, or C/C++ FFI crates.

**Step-2 Divergence Exit Rule:** Check Rust's type/borrow guarantees and explicit bounds guards at the call site first. If safe slice methods (`.get()`), `checked_*` arithmetic, or sound lifetime bounds prevent the condition, close the task with `ajar task dry <task_id> --worker <id> --locus <file:line> --control "<reason>"`.

## Contrastive Pattern Matrix

| Pattern | Defect Pattern & Sinks | Compensating Control That Makes It Safe | 4-Arm Verification Recipe |
| --- | --- | --- | --- |
| **1. Unsound `unsafe` Aliasing, `set_len`, & Lifetime Widening** | `Vec::set_len` called before initializing spare capacity (`MaybeUninit` read before write), raw pointer casts producing simultaneous `&mut T` and `&T` (Stacked/Tree Borrows UB), transmuting lifetimes `'a -> 'static`, or manual `unsafe impl Send/Sync` on non-thread-safe inner pointers. | `Vec::spare_capacity_mut()` initialized completely before `set_len`, `UnsafeCell` + atomic synchronization mediates shared mutation, lifetimes stay tied to owner borrow, and Miri/ASan shows zero aliasing or uninitialized reads. | Arm 1: `cargo +nightly miri test` or ASan/release build PoC triggers UB, uninitialized memory leak, or use-after-free crash. Arm 2: Benign input passes Miri/tests cleanly. Arm 3: Replace `set_len`/raw cast with safe slice/checked `MaybeUninit` initialization. Arm 4: Benign input passes tests cleanly. |
| **2. Untrusted Input Panic DoS (`unwrap`, Indexing, Overflow)** | Network packet, RPC payload, archive header, or untrusted config reaches `slice[idx]`, `str[byte_offset]` (UTF-8 char-boundary panic), `.unwrap()`/`.expect()`, `a / b` (`b == 0`), or debug/overflowing arithmetic in a long-lived server/validator thread (`unchecked-arithmetic-panic-dos`). | `.get(idx)` / `.is_char_boundary()`, `checked_add`/`checked_mul`/`checked_div` returning `Result<_, ParseError>`, and per-request error propagation without tearing down shared worker/consensus state. | Arm 1: Crafted frame/input panics the parser or aborts service process (`RUST_BACKTRACE=1` hits target `file:line`). Arm 2: Valid frame parses and returns `Ok(...)`. Arm 3: Replace unchecked index/arithmetic with `checked_*` / `.get()` returning `Err(...)`. Arm 4: Valid frame still returns `Ok(...)`. |
| **3. Length-Prefixed Allocation Bomb (OOM DoS)** | Wire-protocol decoder reads an untrusted `u32`/`u64` length header and immediately calls `Vec::with_capacity(declared_len)` before verifying that the socket/stream actually holds `declared_len` bytes or enforcing a frame cap. | `declared_len <= MAX_FRAME_BYTES` check before allocation **and** bounded incremental growth (`cap.min(4096)` / `Read::take`). | Arm 1: 8-byte header declaring `u32::MAX` triggers immediate multi-GB allocation failure/OOM abort. Arm 2: Valid bounded frame decodes normally. Arm 3: Cap `with_capacity` against `MAX_FRAME_BYTES` and remaining input length. Arm 4: Valid frame decodes normally. |
| **4. Integer Cast Truncation (`as u32`, `as usize`, `i64 -> usize`)** | Security-critical size, fee, offset, or buffer length uses lossy `as` casts (`u64 as usize` on 32-bit targets, negative `i64 as usize` wrapping to huge value, `usize as u32` truncating high bits before bounds check while full `usize` drives copy). | `usize::try_from(val)?` / `u32::try_from(val)?` rejects out-of-range values prior to bounds checks or allocations (`resource-precision-loss`). | Arm 1: Boundary value (`2^32 + k` or `-1`) passes truncated check and corrupts accounting or triggers OOB/panic. Arm 2: In-range size succeeds. Arm 3: Replace `as` cast with `try_from` error return. Arm 4: In-range size succeeds. |
| **5. Async Cancellation Unsafety & Lock-Across-`.await` Deadlock/TOCTOU** | `tokio::select!` drops an in-progress future mid-`.await` after partial state mutation without a drop guard, or code checks an authorization/balance invariant, drops the mutex across `.await`, and commits mutation on stale state. | Re-validate invariant under the write lock/transaction at commit time, keep state mutations atomic or rollback-guarded on `Drop`, and enforce consistent lock acquisition order. | Arm 1: Concurrent/cancelled async tasks violate balance/nonce invariant or deadlock (`--determinism probabilistic --trials 10`). Arm 2: Sequential/honest concurrent tasks preserve invariant. Arm 3: Move check + mutation inside single atomic critical section / add `Drop` rollback. Arm 4: Honest concurrent tasks pass. |
| **6. FFI Boundary & `CString` / Null-Byte / Ownership Mismatch** | Rust passes non-null-terminated `&[u8]` ptr to C string APIs, frees C-allocated memory with Rust's `Box::from_raw`/`Vec::from_raw_parts` (allocator mismatch), allows interior `\0` path truncation (`CString` vs `OsStr`), or unwinds a Rust `panic!` across `extern "C"`. | `CStr`/`CString::new` rejects interior NULs, paired C destructor frees C allocations, buffer lengths are checked with `checked_mul(size_of::<T>())`, and `catch_unwind` guards `extern "C"` entrypoints. | Arm 1: Interior NUL or crafted FFI buffer triggers path truncation, ASan heap-buffer-overflow, or abort-on-unwind. Arm 2: Valid FFI input succeeds cleanly. Arm 3: Validate `CString::new` / allocator pairing / `catch_unwind`. Arm 4: Valid FFI input passes. |
| **7. Archive / Path / Symlink Extraction Escape** | Tar/Zip/artifact extractor joins archive entry paths onto destination directory without rejecting `..`, absolute roots, or previously extracted symlinks pointing outside the destination root (`O_NOFOLLOW` missing). | Lexical component check rejects `ParentDir`/`RootDir`/`Prefix` **and** open/extract walks components with `openat` + `O_NOFOLLOW` (or canonicalizes existing parent after forbidding symlink entries). | Arm 1: Crafted archive writes or reads file outside extraction directory. Arm 2: Clean archive extracts inside target directory. Arm 3: Reject symlink/parent components and enforce `O_NOFOLLOW`. Arm 4: Clean archive extracts normally. |
